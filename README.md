Apple-inspired SaaS landing page built with the Apple design system.

## Tech Stack
- HTML5 + CSS3 (Design Tokens)
- Tailwind CSS v4 (browser build)
- Lucide Icons

## Design System
Based on the Apple (苹果) design library with:
- Apple System Blue (#007AFF) primary color
- DM Sans typography
- Apple Human Interface Guidelines spacing & radius
